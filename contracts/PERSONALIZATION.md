# 页面抓取配置与来源（当前版本）

## Dify 配置

网页只保留 Dify workflow、沿用网站设置、仅默认规则三个选项，不再提供直接调用 SiliconFlow / DeepSeek 的选项。工作流内部选择哪个模型仍由你在 Dify 管理。

填写：

- API 基础地址：`https://api.dify.ai/v1`。
- API Key：已发布 Workflow 应用的 Key，不是模型供应商 Key。
- 输入变量名：开始节点接收候选 JSON 文本的变量，例如 `payload`。
- 输出变量名：结束节点返回筛选结果的字段，例如 `result`；可填写嵌套字段路径。

基础地址后自动补 `/workflows/run`，旧的完整调用地址也可填写，不会重复拼接。输入按配置写入 `inputs[输入变量名]`，输出从 `data.outputs[输出变量名]` 读取。输入变量类型应为文本/段落，内容是规范候选 JSON；输出支持 JSON文本、JSON对象、带id的已筛选条目数组或id数组，支持 items / filtered_items / decisions 结构。数组空集表示全部删除。模型不能新增不在输入中的id或改写原文链接。

找不到输出变量时显示可用变量名；鉴权失败、输入错误、未发布/运行失败、超时及格式不兼容分别返回可操作提示，不回退默认内容规则。完整JSON输出允许保留项重新排序，网页使用原始来源元数据。

Key只在当前页面内存，刷新或关闭后清除，不写入网址、浏览器永久存储、JSON导出文件或仓库。请求经本站HTTPS后端调用Dify。支持Dify Cloud；自建Dify精确域名仍需服务端 `AI_WORKFLOW_ALLOWED_HOSTS` 允许。整个页面配置仅影响本页面，不是全站公开配置写接口。

## 小红书图文

下拉来源增加“小红书图文”，全部来源/图文来源也纳入小红书候选。读取在腾讯云EdgeOne后端执行。腾讯云部署MCP本身不是小红书登录或搜索API。

默认尝试小红书公开搜索页，仅解析页面公开的图文笔记初始状态，不执行网页脚本，不模拟账号、签名或绕过登录。只返回拿到原标题、笔记id、原文地址及可用简介/封面的真实图文条目；排除视频笔记。缺封面使用占位图，缺简介明确标为未获取，不生成笔记正文。

遇到登录/风控/页面格式变化时，返回来源不可用的明确状态；其他来源继续正常返回，不拿旧目录冒充小红书结果。本次按要求未实际读取或测试小红书页面，因此不能确认当前公网出口可正常读取。

需要稳定授权源时，EdgeOne可配置：

```dotenv
XIAOHONGSHU_SOURCE_URL=https://你的授权服务/notes
XIAOHONGSHU_SOURCE_TOKEN=可选授权令牌
```

接口GET接收q/page，返回 `{items:[...],hasMore:true}`。每条保留24位笔记id、小红书原文URL、type=normal/image/multi、原标题、真实简介、cover/imageList、作者。凭据只放服务端。输入字段可以兼容常见noteCard/note_card结构，原文域名限制在小红书。
