# UnBrainrot MVP

有限推荐、跨来源精选目录和专注探索的网页原型。无依赖静态站点。

## 本地运行

需要 Node.js 18 或更新版本，在 web 目录运行 `npm start`，访问 http://127.0.0.1:4173 。运行 `npm run check` 检查脚本语法。

## 功能

- 12 项起步内容目录，主题、来源与关键词筛选。
- 每批 6 项探索，不自动无限加载。
- 收藏、最近访问、探索问题保存在当前浏览器 localStorage，无账号、无云同步。
- 20 分钟探索提醒，结束后记录一个后续问题。页面关闭后不继续提醒。
- 响应式布局、键盘导航、搜索快捷键 `/`。

## 部署

`dist/` 可直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或任何静态托管平台，无需构建。仓库附带 GitHub Pages Actions 工作流；仓库 Settings → Pages → Source 选择 GitHub Actions 后运行工作流。

## 当前边界

这不是实时全网搜索服务。目录人工整理，不抓取平台内容、不执行 AI 质量评分。内容包括视频、文档、课程和专题入口；封面为 CSS 原创主题图，非原站封面。访问原站会离开本应用，不能阻止原站相关推荐；没有内嵌播放器或平台屏蔽插件。部分外部资源为英文，原站访问条件及可用性由原站决定。

后续应优先验证用户是否反复使用目录搜索，再接入经过授权的内容源和后端索引。不要把来源覆盖、真实性审核或注意力改善当作已完成能力。
